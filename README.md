# one-dark-theme-vscode

To use it locally:

- Open VS Code.
- Run Developer: `Install Extension from Location`
- Pick the folder `one-dark-theme-vscode`
- Reload when prompted.
- Run Preferences: Color Theme and choose `One Dark`.


Use this VS Code command:

- Press `Cmd+Shift+P`
- Run Developer: `Inspect Editor Tokens and Scopes`
- Click on the text/token in the editor
